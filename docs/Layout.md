# Layout

Every source file of the plugin and what it holds. Keep it in step with the files in the same change that adds, moves or removes one.

| Path | Role |
|------|------|
| `Plugin.cs` | The `BaseUnityPlugin` entry point: identity, dependency, and each feature's per-frame tick isolated in `Run` so one failing feature never stops the others |
| `DebugLog.cs` | The hidden debug log (`[Debug] Debug Log`, on in a test build): every method of this plugin traced through its own Harmony id, settings and their changes, SeneaL UI's policy, this plugin's patches and its log lines, written to `BepInEx\SeneaL UI Unlocker Debug.log`; classes built on the 1.2.0 HUD editor are left untraced on SeneaL UI 1.1.x, where inspecting them crashes the runtime |
| `RetiredSettings.cs` | Removes settings this plugin no longer binds (the renamed `[Map Cheats]` and `[Beyond Maximums]` sections and each removed or moved key) from its settings file at startup; the debug log lists any other setting in the file that nothing binds |
| `ServerRules.cs` | The [Server Rules] a host sends to joining players with this plugin (one Allow per feature, cheats denied by default) over the connection's own RPC `alkeari.senealuiunlocker.rules`, and `Allows(key)`, which every feature checks; a server without this plugin never answers, so everything follows the player |
| `PolicyUnlock.cs` | Reads and sets SeneaL UI's `Policy` state through reflection; shows SeneaL UI's popup when the option is off; adds the player's own value for every rule a SeneaL UI server's answer leaves out, before SeneaL UI reads it (prefix on the game's `ZRpc.HandlePackage`) |
| `MainMenuModSettings.cs` | Builds SeneaL UI's mod settings window on the main menu, where SeneaL UI waits for its in-game HUD, so its key works there, and adds the Mod Settings button that opens it |
| `Settings.cs` | Every BepInEx setting of the plugin |
| `ServerDirectory.cs` | The servers the client knows (game Favorite and Recent lists, QuickConnect's file) and the server being joined |
| `OtherChoices.cs` | The choices whose lists are not every possible answer, their Other value and what a typed answer does; `SettingsPage.cs` swaps the dropdown for a text box when Other is picked |
| `SeneaLConfig.cs` | SeneaL UI's own ConfigFile (`Prefs.Cfg`) and batched writes to it |
| `PresetFix.cs` | Sets the interface preset settings SeneaL UI skips past its setting limit, read from `Profiles.Parse` (900 in early 1.2.0 previews, 6000 later) |
| `LayoutSettingsHider.cs` | Hides SeneaL UI's HUD editor settings from the mod settings window with `ConfigurationManagerAttributes.Browsable` |
| `CraftingPlacement.cs` | With `Merge Crafting Elements` off, separate Crafting window placements beside the inventory and at stations |
| `SeneaLCalls.cs` | SeneaL UI methods called by name (sorting, locks, restock chests, quick stack permission) |
| `ResolutionScale.cs` | Scale With Resolution: this mod's canvases (cards, Party HUD, Skill Progress, Tracker, Food Planner, Cosmetics, stash button) and the chat box take min(width / 2560, height / 1440) times the game's GUI scale, as SeneaL UI's elements do through the game's `GuiScaler` |
| `SafetyFeatures.cs` | Dropped item ping, character backup |
| `InventoryFeatures.cs` | Sort by value, auto-sort chests, restock to targets |
| `Reminders.cs` | Durability, food, Rested and buff reminders, auto-eat |
| `PerPlaceSettings.cs` | Interface preset per server or world, recipe pins per character |
| `StationAndMapHelpers.cs` | Death pin removal, auto-repair at stations, installed-mod checks |
| `SplitWheel.cs` | Mouse wheel in SeneaL UI's split dialog |
| `LayoutArea.cs` | Keep Layout In 16:9 Area: every placed element's SeneaL UI position kept as a share of a centered 16:9 area (hidden `Layout Area Positions`, `Layout Area Shape`) and written into SeneaL UI's Layout X and Y for the screen's shape; the built-in preset's positions are adopted as 16:9 shares |
| `Loadouts.cs` | Four equipment loadouts per character |
| `CombatHud.cs` | Fades chosen SeneaL UI HUD elements out of combat with a CanvasGroup of its own |
| `DepletedOrePins.cs` | Removes ore pins SeneaL UI marks depleted, through `OreScout.Forget` |
| `UpdateNotice.cs` | Reads `https://alkeari.com/updates/seneal-ui-unlocker.json` once per game start through `UnityWebRequest` and shows a top-left message after the first spawn when its newest version is above the installed one |
| `RadarAlerts.cs` | Radar alerts, ignore list and the line-of-sight rule, only with SeneaL Radar installed |
| `ChatFilters.cs` | Chat filters and colors by message type, timestamps on chat lines, shouts and whispers in the case they were typed, and join and leave notices from the game's player list |
